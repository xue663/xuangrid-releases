# 日常使用指南

新安装请先阅读 [安装与升级](installation.md)，按网页六步引导完成首次启动。下面说明已经安装后的日常操作。

## 每次检查什么

1. **总览**：运行状态、行情与账户快照延迟、当前仓位和最新事件。
2. **策略中心**：当前方向、参数和挂单；调整前先预演并处理页面列出的阻塞。
3. **风控中心**：先看当前结论和建议操作，再查看保证金、强平距离、容量等依据。
4. **订单与收益**：核对真实平仓保护单、成交明细、资金费和收益账本。
5. **通知设置**：配置飞书、钉钉或 Telegram，发送测试消息确认可达。

AI 助手和策略方案用于理解行情、证据与操作选择；执行操作仍以实时检查和界面确认结果为准。

## 暂停、恢复与保证金

人工暂停后不会自动恢复。先确认风险阻塞解除、账户快照正常、平仓保护单覆盖当前仓位，再手动恢复。

保证金后台核查中不要重复划转或反复恢复。旧疑难记录按“检查当前账户 → 管理员密码确认”处理，系统保存审计依据，处理后保持暂停。

## 新购、续费与迁移

- 新购：在 [购买页面](https://www.1990663.xyz/buy/) 选择套餐，按提示支付，确认后查询原订单获取激活码。已付款但未确认时不要重复支付。
- 续费：在 [客户门户](https://www.1990663.xyz/portal/) 登录，选择对应授权，点击 **续费此授权**。普通新购会单独发码，不自动叠加旧授权。
- 换设备：先停止旧设备策略，按 [迁移指南](activation.md) 备份、迁移完整数据并办理解绑；不要让新旧设备同时管理同一交易账户。
- 常规升级：保留原配置与完整数据，通常无需解绑，按 [升级步骤](installation.md) 操作。
