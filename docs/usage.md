# 应用安装与使用指南

本文覆盖官网提供的四个用户入口：Windows 控制台、Linux/Docker 实例、在线演示、购买与客户门户。首次使用请先在币安测试网完成验证，再切换主网。

## Windows x64 控制台

### 安装

1. 从 [GitHub Releases](https://github.com/xue663/xuangrid-releases/releases/latest) 下载 `grid-v7-<version>-win-x64.zip` 与同名 `.sha256`。
2. 在 PowerShell 中核对压缩包哈希与 `.sha256` 文件一致。
3. 解压到不含中文和空格的目录，例如 `D:\xuangrid`。
4. 进入解压后的最内层目录，双击 `run.bat`。不要直接运行 `grid-v7.exe`。
5. 保持黑色控制台窗口开启，浏览器自动打开 `http://127.0.0.1:8787`；未自动打开时手动访问。

### 初始化

1. 创建管理员账号并妥善保存登录信息。
2. 首次部署选择测试网。
3. 在交易所设置中填写币安 API Key，只开启读取和交易权限，关闭提现权限。
4. 如服务器有固定出口 IP，配置币安 IP 白名单。
5. 在「订阅与授权」输入激活码，或申请一次设备试用。
6. 确认版本、许可证套餐、设备指纹和到期时间显示正常。

### 日常使用

1. 总览页检查行情延迟、仓位、保证金、强平距离、容量和最新事件。
2. 策略中心查看运行现状、参数预演和变更记录。
3. 风控中心查看实时风险、未来预测和风险顾问建议。
4. 收益页核对收益日历、平仓明细、外部成交和资金费归因。
5. 出现预警时先查看事件说明和审计日志，再执行暂停、恢复或保护操作。
6. 需要长期运行时使用 NSSM 运行 `install_service.bat`，并确认服务开机自启。

### 升级与备份

1. 停止策略程序或 Windows 服务。
2. 备份 `config.yaml`、`data/`、`logs/`。
3. 解压新版本到新目录，不要直接覆盖旧目录。
4. 将旧配置和数据复制到新目录对应位置。
5. 启动新版本，核对版本、许可证、持仓、挂单和事件流。

## Linux / Docker 实例

### 安装

1. 准备 Ubuntu 22.04 或 24.04、Docker Engine，并确认服务器可访问币安 API。
2. 创建持久化目录：

```bash
mkdir -p ~/xuangrid/{config,data,logs}
```

3. 授权容器内 UID 10001 写入：

```bash
sudo chown -R 10001:10001 ~/xuangrid/{config,data,logs}
```

4. 启动容器：

```bash
docker run -d --name xuangrid --restart unless-stopped \
  -p 8787:8787 \
  -v ~/xuangrid/config:/app/config \
  -v ~/xuangrid/data:/app/data \
  -v ~/xuangrid/logs:/app/logs \
  -e TZ=Asia/Shanghai \
  ghcr.io/xue663/xuangrid:7.1.7
```

5. 执行 `docker ps` 与 `docker logs -f xuangrid`，确认容器运行、配置生成且无 Permission denied。

### 初始化

1. 浏览器打开 `http://<服务器IP>:8787`。
2. 创建管理员账号。
3. 首次部署选择测试网并配置币安 API Key。
4. 关闭 API Key 提现权限，并配置服务器 IP 白名单。
5. 在「订阅与授权」输入激活码并确认设备绑定。

### 日常使用

1. Web 总览页检查运行状态、行情延迟、仓位与风险指标。
2. 策略中心查看运行现状、参数预演和变更记录。
3. 风控中心处理实时风险、未来预测和风险顾问提示。
4. 服务器端定期检查 `docker ps`、磁盘空间、容器日志和系统时间。
5. 只通过 Web 控制台执行控制命令；不要直接修改数据库或交易所挂单。

### 升级

1. 在 Web 中暂停新增风险，确认没有待处理的参数应用。
2. 备份宿主机 `config/`、`data/`、`logs/` 三个目录。
3. 拉取新镜像：

```bash
docker pull ghcr.io/xue663/xuangrid:7.1.7
```

4. 删除旧容器，并用原来的端口、环境变量和挂载路径重建容器。
5. 核对 Web 版本、许可证、持仓、挂单、事件流和日志。

## 购买与客户门户

### 购买与激活

1. 打开 [购买页面](https://www.1990663.xyz/buy/)，选择 BASE、PRO 或 ELITE。
2. 按页面提示使用 USDT TRC20 支付。
3. 到账确认后，保存页面显示的激活码。
4. 进入 XuanGrid Web 的「订阅与授权」，输入激活码。
5. 确认套餐、设备指纹、租约和到期时间。

### 管理订阅

1. 打开 [客户门户](https://www.1990663.xyz/portal/)。
2. 使用购买邮箱和激活码登录。
3. 查看订阅有效期、当前绑定设备和续费状态。
4. 同邮箱续费同套餐会自动叠加时长。
5. 续费后回到应用检查许可证租约是否刷新。

### 换机迁移

1. 在旧设备停止策略或关闭程序。
2. 在客户门户解绑旧设备。
3. 在新 Windows 或 Docker 实例完成部署。
4. 使用原激活码激活新设备。
5. 核对持仓、挂单、许可证和通知后再恢复运行。
