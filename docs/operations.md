# 暂停、保证金核查与运行提醒

适用于 1.5.0 及以上。先看风控中心显示的原因，再判断是否需要操作。

## 保证金划转显示“后台核查中”

交易所响应暂时不能证明划转结果时，系统继续核对到账记录和账户状态，暂时停止新增风险，并保留保护行为。

无需重复发送划转或反复点击恢复。结果明确且风险、保护检查通过后，符合自动恢复条件的临时保护可自动解除；你主动暂停的策略仍保持暂停。系统查询失败时不会据此判断划转未执行。

## 等待较久，或旧记录一直阻塞恢复

1. 打开风控中心的保证金待确认记录，点击 **检查当前账户**。
2. 阅读检查结果。系统核对账户、账本、风险和真实保护单；不满足条件时，按页面说明处理后重新检查。
3. 系统允许按当前账户处理时，管理员输入本实例 Web 密码，点击 **确认按当前账户处理**。

无需手填审计证据，系统自动保存检查依据及操作记录。确认前账户变化会拒绝旧结果并要求重新检查。

这一步结束旧记录对当前策略的阻塞，**不会把未知历史结果认定为已到账或未执行，也不会重发原划转**。处理后保持暂停；检查风控中心没有其他阻塞、保护单正常后，在策略控制中手动恢复。

## 策略暂停，但不知道原因

查看当前状态说明和同一时间的事件记录。行情超时、风险保护、调整过程和人工暂停处理方式不同，不能仅凭“暂停”判断故障。

先确认行情恢复、账户快照正常、保护单覆盖仓位，再按界面指引操作。恢复后立即再次暂停时，说明仍有阻塞，不要反复点击恢复；保存发生时间、页面原因和脱敏日志交给支持人员。

## 如何阅读运行通知

运行提醒说明 **发生的情况、当前影响和下一步**。保证金按当前账户处理完成时，会明确提醒策略仍保持暂停，以及何时可以手动恢复。

没有实际操作价值的区间观察和普通冲击观察减少推送，真实错误与主动保护仍保留。提醒不是每条都要求操作；以“下一步”和 Web 当前状态为准，完整记录在实例事件与审计中查看。
