# 激活、续费与设备迁移

## 先分清三种信息

- **一次性初始化码**：创建本实例管理员，首次页面通常自动填入。
- **管理员账号和密码**：登录控制台及确认受控操作，由你设置。
- **订阅激活码**：启用购买的套餐，不代替管理员密码。

## 新购与激活

1. 打开 [购买页面](https://www.1990663.xyz/buy/)，选择套餐与时长，填写邮箱并下单。
2. 按订单提示使用 USDT TRC20 支付。到账确认后查询原订单，保存激活码；未确认时不要重复付款。
3. 在首次引导的“激活或试用”，或控制台“订阅与授权”输入激活码。
4. 核对套餐、绑定设备和到期时间。激活后继续连接账户、配置、预演并确认启动；激活不会自动交易。

申请试用按页面提示操作，同一设备只能申请一次。设备授权信息自动保存在实例数据目录。

## 已有授权续费

1. 使用购买邮箱和激活码登录 [客户门户](https://www.1990663.xyz/portal/)。
2. 在对应授权卡点击 **续费此授权**，按续费订单付款。
3. 确认该授权到期时间延长，回客户端刷新授权状态。

续费无需更换原激活码。**普通新购订单会单独发码，不自动给旧授权叠加时长**。到期可能进入仅保护状态；续费不会自动恢复人工暂停的策略，先核对风险与保护状态再手动恢复。

## 常规版本升级

保留原配置和完整数据目录即可保留设备身份及授权，通常无需解绑。升级后突然提示新设备或未激活，先检查程序是否使用了原数据目录，不要删除数据后重试。

## 换设备迁移

1. 在旧设备暂停策略，核对平仓保护单，停止程序或容器后备份完整配置和数据。
2. 安装新设备并迁移原配置及完整数据；不要让两个实例同时管理同一交易账户。
3. 需要切换授权绑定时，在客户门户解绑旧设备，再在新设备输入原激活码激活。解绑会使旧设备授权失效。
4. 核对新设备版本、授权、仓位、账本和真实保护单，处理风险阻塞后再手动恢复。

每个激活码绑定一台设备。如果客户端明确提示“设备身份格式已退役”，先备份配置和数据，再按“试用与设备”页面提示用本实例管理员密码重绑；已有旧绑定时需在门户办理解绑。更换激活码不能替代设备重绑。
