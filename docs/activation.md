# 激活与设备迁移

## 购买

1. 打开 [购买页面](https://www.1990663.xyz/buy/)
2. 选择套餐与购买时长，填写邮箱并下单
3. USDT TRC20 到账后自动发放激活码，购买页面实时显示

同邮箱购买同一套餐会自动叠加时长，无需重复输入多个激活码。

## 激活

1. 启动 XuanGrid，打开 `http://<服务器>:8787`
2. 进入「诊断 → 许可证」
3. 输入激活码并点击激活

激活后程序会自动保存设备密钥，后续刷新许可证不再需要输入激活码。

## 设备迁移

1. 打开 [客户门户](https://www.1990663.xyz/portal/)
2. 使用购买邮箱与激活码登录
3. 在对应套餐下点击「解绑设备并迁移」，旧设备授权立即失效
4. 在新设备上重新输入同一激活码完成激活

每个激活码默认只支持 1 台设备，换设备前必须先解绑旧设备。

## 到期与续费

- 到期前系统会通过通知渠道提醒
- 在购买页用同一邮箱续费，激活码有效期自动顺延
- 到期后进入仅保护模式，续费并刷新许可证后恢复完整功能
