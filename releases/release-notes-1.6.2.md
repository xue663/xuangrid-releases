# XuanGrid 1.6.2 更新说明

本次补丁修复方向策略在手动平仓后重新启动时可能持续停留在防冲击状态的问题。

- 启动阶段会继续执行防冲击的小时线核验，解除条件不再因尚未建立初始网格而暂停。
- 冲击尚未解除时，逆势新增开仓仍会被拦截，风险保护不会被绕过。
- 防冲击解除后，策略可按原有流程建立初始网格。
- 现有策略参数、历史数据、授权和保护单保持不变。

Windows 用户下载本页的 `xuangrid-1.6.2-win-x64.zip` 和同名 `.sha256` 文件。Linux、飞牛及 NAS 用户使用 Docker Hub 镜像 `jun663/xuangrid:1.6.2`。
