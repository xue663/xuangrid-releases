# XuanGrid 1.6.0

## 账户模式预检与一键修复

- 首次连接币安 USD-M 合约前，先检查账户级资产模式与持仓模式，提前发现 Multi-Assets 与 One-way 等不符合要求的设置，避免问题延迟到启动后才暴露。
- 交易所连接页新增资产模式、持仓模式、全账户持仓和挂单状态，并在需要时提供明确确认后的一键修复。
- 一键修复仅在没有持仓和挂单时执行，只修改不满足的设置，修改后立即复读验证；常规启动和逐仓设置仍只检查，不会静默改动账户级模式。

## 参数变更记录

- 参数中心的变更记录改为完整账本：顶部概览、记录索引和详情面板分层展示，不再把全部审计信息挤在窄滚动窗口里。
- 查看任意方案时集中展示调参目标、关键配置、风险差异和受控应用时间线；审批、应用与撤销操作仍在选中方案内完成，并保留密码、交易对和风险确认。
- 适配桌面、窄屏、手机和 200% 缩放。
