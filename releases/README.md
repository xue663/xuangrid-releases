# 发布产物

当前稳定版 **1.4.5**。从 [GitHub Release](https://github.com/xue663/xuangrid-releases/releases/tag/v1.4.5) 下载 Windows x64 ZIP 与同名 `.sha256` 文件。

Linux、飞牛及兼容 NAS 使用 [Docker Hub](https://hub.docker.com/r/jun663/xuangrid) 的 `jun663/xuangrid:1.4.5`，支持 Linux amd64 / x86_64。`latest` 会随后续正式发布变化。

GitHub 页面上的 “Source code (zip/tar.gz)” 是本发布仓库的文档快照，**不是机器人安装包**。Windows 请选择名称包含 `win-x64.zip` 的附件。

[安装与升级](../docs/installation.md) · [1.4.5 更新说明](release-notes-1.4.5.md)

`latest.json` 记录当前公开版本、时间、安装包名称和 Docker 镜像。历史更新说明用于查阅，安装请选择当前稳定版。
