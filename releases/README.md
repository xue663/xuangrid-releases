# Releases

当前正式版本在 GitHub Releases 提供以下下载：

- `xuangrid-<version>-win-x64.zip`：Windows x64 安装包
- 对应的 `.sha256` 校验文件

Linux 用户统一使用 Docker Hub 镜像 `jun663/xuangrid`。

`latest.json` 记录当前最新版本、发布时间、安装包名称和 Docker 镜像。

旧版 Windows 下载已停止提供，历史发布记录仅供查阅。请使用 [最新版本](https://github.com/xue663/xuangrid-releases/releases/latest)。
