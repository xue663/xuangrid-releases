## XuanGrid 1.3.0 更新内容

### 参数中心（新功能）

- 新增「参数中心」页面：集中管理所有运行参数，常用开关一键调整
- 运行开关区支持：恢复模式、网格间距、冲击防护、趋势刹车、自动保证金缓冲
- 每个开关标注生效方式（下次 Epoch 重建 / 保护重载），改前就知道影响范围
- 17 项防护与恢复细节参数进入 Web 预演：冲击快速 ATR、速度阈值、库存速度阈值、ATR/TR 比、间距倍数、退出确认等
- 支持重建执行入口（持仓重建 / 受控重建）

### 界面优化

- 策略中心精简为纯运行监控（策略脉冲、网格坐标、参数摘要、账户快照）
- 参数调整、完整预演、变更记录统一收归参数中心，消除双入口
- 分段开关和快捷卡片全新设计，桌面端多列、手机端单列，文字不遮挡
- 快捷开关确认支持 15 分钟内记住验证，减少重复输入

### 新实例部署

- 新增 Web 端运行环境切换：测试网与主网之间一键切换，无需手动修改配置文件
- 切换主网时自动写入初始本金和确认开关，受控重启后生效

### 稳定性

- 修复网格步长不是最小报价单位整数倍时 epoch 重建可能失败的问题
- 默认恢复模式改为区间桥接：平仓梯从市价侧最近被动格连续排列，小幅回撤即可逐格退出
- 修复市价阶梯首格可能落在标记价上的问题

### 升级说明

- 升级时保留配置和数据目录
- 已有许可证激活自动延续
- 从 1.3.0 升级无需手动操作
