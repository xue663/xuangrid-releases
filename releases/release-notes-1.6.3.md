# XuanGrid 1.6.3 更新说明

本次补丁重点修复策略中断后的恢复体验、防冲击核验连续性，并改进控制台可读性。

- 人工暂停、停止或全平中断受控重建时，旧重建流程会进入明确的待复核终态，不再永久显示“重建中”，也不会阻塞后续安全复核。
- 重启后会回读停机期间已收盘的小时线；数据完整且行情恢复平静时，防冲击自动核验继续累计，不因停机重新计数。
- 防冲击未解除前仍会拦截逆势新增开仓；已有保护性平仓继续维护，风险保护不会被绕过。
- 持仓恢复窗口加宽并重排关键事实、结论和下一步，长文本不再挤压不可读。
- 系统状态说明改为稳定浮层，鼠标悬停或键盘聚焦时可查看原因、影响、建议和恢复条件。
- AI 模型方案新增按模型保存的上下文窗口设置，单位为 tokens，系统会为证据和输出预留空间。

Windows 用户下载本页的 `xuangrid-1.6.3-win-x64.zip` 和同名 `.sha256` 文件。Linux、飞牛及 NAS 用户使用 Docker Hub 镜像 `jun663/xuangrid:1.6.3`。
