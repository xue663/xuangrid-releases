# XuanGrid 1.4.0

本次更新重构客户端系统管理，改善手机 Web 使用体验，并让通知结果与风险状态更容易核对。

- 通知中心分为「通知通道」「类别与计划」「投递记录」。可按通道、失败或排队状态筛选最近记录，展开查看投递时间、尝试次数与失败原因。
- 通知类别重新分组，手机上可完整阅读说明、操作开关并设置心跳与每日汇总；切换标签保留未保存的类别设置。
- 系统诊断与审计日志合并为「运行与日志」，支持状态核对和逐条展开事件，原有入口链接继续兼容。
- 手机上的账号管理改为先选账号、再查看详情；交易所连接按连接状态、凭证与环境、网络代理组织，保留首次配置引导。
- 订阅页面集中展示当前套餐与有效期，试用、设备信息和授权详情按需展开。
- 风控页面突出当前值、阈值与余量；数据缺失或过期时显示待核验。总览减少重复摘要，当前价格改用易与开多订单区分的颜色。
- 参数方案与当前策略方向不一致时提供明确提示，并保留独立的方向切换确认流程。
- 补齐相关读取失败重试、键盘操作和英文／繁体中文文案。

现有套餐权益、管理员验证和交易确认流程保持不变。升级前请暂停策略并备份配置与数据；升级后核对持仓、订单和保护状态，再由本人决定是否恢复运行。

Windows 用户下载本页的安装包；Linux 用户使用 Docker Hub 镜像 `jun663/xuangrid:1.4.0`。
