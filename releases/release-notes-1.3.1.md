## XuanGrid 1.3.1 更新内容

### 新实例部署修复

- 修复首次激活时选择测试网 / 主网后无法完成环境切换与受控重启的问题。
- 首次激活现在可直接选择运行环境，并一次提交 Binance API 凭证。
- 选择主网时，系统会先用主网接口验证 API 凭证，通过后自动读取合约钱包余额作为初始本金，无需手工估算填写。
- 主网合约钱包余额为 0 时拒绝激活，避免带错误本金基数启动。
- 目标环境账户如存在持仓或挂单，首次激活会继续执行空仓保护检查。

### 交易所连接页

- 环境切换确认区补充管理员密码输入，按钮不可用时原因更清晰。
- 提供初始本金自动读取说明；仍保留手工填写初始本金的方式。
- 保存或切换凭证时继续要求确认 API Key 未开启提现权限。

### 防护状态恢复

- 改善趋势与冲击防护在重启后的状态恢复，保留已确认的防护状态及必要观察记录，同时保留手动暂停意图。
- 修正冲击速度的短周期与长周期判断，并加强退出防护时对重复、缺失行情的检查。
- 中断后的冲击扩距会通过安全重建流程重试。

### 升级说明

- 升级时保留配置、许可证和数据目录。
- 升级前请暂停策略并备份；已暂停策略不会因升级自动恢复，升级后确认状态再按原有流程手动恢复。
- 从 1.3.0 升级无需迁移数据。
